# MiniTotemCancel

Simple addon that creates 4 buttons to use in macros for cancelling your totems.

Create a macro like this:

```
/click TotemFrameTotem1 RightButton 1
/click TotemFrameTotem2 RightButton 1
/click TotemFrameTotem3 RightButton 1
/click TotemFrameTotem4 RightButton 1
```

Press the macro and it'll destroy your active totems.
